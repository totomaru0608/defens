# 🛡️ 코인 수비대 (Coin Defense Squad)

브라우저에서 바로 플레이할 수 있는 **3D 로우폴리 아이소메트릭 타워 디펜스 액션 웹 게임**입니다.  
외부 3D 모델이나 이미지/오디오 에셋 없이 **Three.js 절차적(Procedural) 지오메트리·다관절 리깅**과 **Web Audio API**만으로 구현되었습니다.

---

## 🎮 주요 특징

- **아이소메트릭 3D 로우폴리 그래픽 & 다채로운 지형물**:
  - 초록색 들판, 밝은 모래색의 구불구불한 큰 길(`CatmullRomCurve3`), 왕국의 작은 성채와 주변 성벽·망루
  - **6종 3D 로우폴리 지형물**: `🌲 숲/나무`, `🪨 바위군`, `💧 호수(수련잎·갈대)`, `🌊 강줄기(목재 다리)`, `⛰️ 만년설 산봉우리`, `🪧 나무 이정표(랜턴)`
- **🐘 코끼리 · 🦛 하마 · 🦒 기린 다관절 동물 적 & ComfyUI 모션 스튜디오**:
  - **🐘 붉은 전투코끼리**: 4족 대각선 교차 보행 + 2단 관절 코(Trunk) 상하/좌우 휘젓기 + 큰 귀 펄럭임 애니메이션
  - **🦛 진홍 강철하마**: 뒤뚱거리는 4족 돌격 보행 + 거대한 아래턱(`jawPivot`)을 크게 벌렸다 다무는 개폐(Chomp) 애니메이션
  - **🦒 홍련 기린**: 성큼성큼 내딛는 긴 다리 질주 + 긴 목(`neckPivot`) 앞뒤/좌우 리듬 스웨이 애니메이션
  - **🎨 인게임 ComfyUI 3D 동물 모션 노드 스튜디오**: 3D 실시간 턴테이블 프리뷰를 보며 보행 속도(`stride_speed`), 다리 보폭(`leg_swing`), 특수 부위 동작 강도, 크기 배율을 조절하고 `⚡ Queue Prompt`로 전장에 즉시 소환하거나 ComfyUI Workflow JSON으로 저장 가능
- **🛠️ 인게임 3D 스테이지 · 지형 · 맵 · 웨이브 통합 에디터**:
  - 스테이지 무제한 추가(`+ 스테이지 추가`), 수정(이름·시작 코인·성채 체력), 삭제(`🗑️ 스테이지 삭제`), 기본값 복원 및 `localStorage` 자동 저장
  - 마우스 실시간 3D 프리뷰를 보며 `🌲 숲`, `🪨 바위`, `💧 호수`, `🌊 강`, `⛰️ 산`, `🪧 이정표`, `🪙 건설구역`, **`📍 길경로점(Waypoint)`**을 클릭 배치·이동하거나 우클릭으로 즉시 삭제
  - **`🗺️ 맵·웨이브 편집` 스튜디오**:
    - **6종 지형 테마 프리셋 & 4종 커스텀 색상 피커**: `🌿 초록 들판`, `🌾 황혼 대평원`, `💎 에메랄드 고원`, `🏜️ 사막 협곡`, `❄️ 만년설 요새`, `🌋 암흑 화산지대` 및 들판·언덕·모래길·테두리 색상 실시간 변경
    - **모래길 모양 프리셋 & 자동 생성**: 6종 경로 프리셋(`🐍 S자 굽잇길`, `⚡ 지그재그`, `🌀 이중 루프`, `🐉 6단 구불길`, `🌈 대형 아치`, `🏹 대각선 급습`), `🎲 랜덤 구불길`, `⇄ 출발·성채 반전`, `🏗️ 건설구역 자동배치`, 경유지 `(X, Z)` 좌표 편집
    - **적 웨이브 & 군단 편성 편집**: 웨이브 추가/삭제, **`⚡ 이 웨이브 즉시 출격`** 테스트, 8종 적(`🦒 기린`, `🦛 하마`, `🐘 코끼리`, `👹 돌격병`, `⚔️ 전사`, `🔥 기습병`, `🛡️ 중장갑`, `👑 보스`) 그룹별 마릿수·스폰 간격·출현 지연시간 조절
- **마우스 레이캐스팅 부드러운 이동 & 추적 카메라**:
  - 마우스 포인터 위치를 3D 지면 좌표로 실시간 변환(`THREE.Raycaster`)하고, 속도·가속도·감속(Arrival Damping) 및 맵 경계 제한(Clamp)을 적용해 순간이동 없이 자연스럽게 이동
  - 플레이어를 화면 중심 부근에 부드럽게 유지하는 아이소메트릭 카메라
- **직접 공격 & 방어탑 협동 디펜스 (기본 6개 스테이지 + 무제한 커스텀 확장)**:
  - 수비대장의 근접 자동 범위 참격 + **황금 충격파 베기**(좌클릭 / `Space`) 액티브 스킬
  - 적 처치 시 드롭되는 3D 코인으로 길 주변 지정 건설 구역에 **연사 석궁탑(1)**, **화염 대포탑(2)**, **빙결 수정탑(3)** 설치 및 최대 Lv.3 강화

---

## 🚀 실행 방법

```bash
# 1. 의존성 설치 (최초 1회)
npm install

# 2. 개발 서버 실행 (브라우저에서 바로 플레이)
npm run dev

# 3. 프로덕션 빌드
npm run build
```

## 🕹️ 조작 방법

| 조작 | 설명 |
| :--- | :--- |
| **마우스 이동** | 마우스 포인터가 가리키는 3D 지면 목표 지점을 향해 가속/감속하며 부드럽게 이동 |
| **적 접근** | 사거리 내 적과 야수 군단에게 자동으로 검을 휘둘러 범위 공격 |
| **마우스 좌클릭 / `Space`** | **황금 충격파 베기** 스킬 발동 (광역 피해 + 감속) |
| **건설 구역 위에 서기** | 보유 코인을 자동으로 투입해 선택된 방어탑 건설 및 강화 (최대 Lv.3) |
| **숫자키 `1` / `2` / `3`** | 건설할 방어탑 종류 선택 (`1`: 연사 석궁탑, `2`: 화염 대포탑, `3`: 빙결 수정탑) |
| **우측 상단 `🎨 ComfyUI 모션`** | 코끼리·하마·기린 3D 관절 모션 노드 편집 및 전장 즉시 소환 |
| **우측 상단 `🛠️ 에디터`** | 스테이지 추가/수정/삭제 및 숲·바위·호수·강·산·이정표·길경로점(`📍`) 3D 배치/삭제 |
| **에디터 상단 `🗺️ 맵·웨이브 편집`** | 스테이지 지형 테마·모래길 경로(Waypoint)·웨이브별 적 종류/마릿수/스폰 간격 상세 편집 |
