# 🛡️ 코인 수비대 (Coin Defense Squad)

브라우저에서 바로 플레이할 수 있는 **3D 로우폴리 아이소메트릭 타워 디펜스 액션 웹 게임**입니다.  
외부 3D 모델이나 이미지/오디오 에셋 없이 **Three.js 절차적(Procedural) 지오메트리**와 **Web Audio API**만으로 구현되었습니다.

---

## 🎮 주요 특징

- **아이소메트릭 3D 로우폴리 그래픽**: 초록색 들판, 밝은 모래색의 구불구불한 큰 길, 주변 성벽과 작은 성채, 나무와 바위 등 캐주얼하고 선명한 로우폴리 비주얼
- **마우스 레이캐스팅 부드러운 이동**: 마우스 포인터 위치를 3D 지면 좌표로 실시간 변환(`THREE.Raycaster`)하고, 속도·가속도·감속(Arrival Damping) 및 맵 경계 제한(Clamp)을 적용해 순간이동 없이 자연스럽게 이동
- **플레이어 추적 카메라**: 플레이어의 이동을 부드럽게 보간(Lerp)하여 화면 중심 부근에 유지하는 아이소메트릭 카메라
- **직접 공격 & 방어탑 협동 디펜스**:
  - 수비대장(플레이어)의 근접 자동 범위 참격 + **황금 충격파 베기**(좌클릭 / `Space`) 액티브 스킬
  - 적 처치 시 튀어나오는 입체 3D 코인 획득
  - 길 주변 지정 **건설 구역** 위에 표시된 코인 비용(`🪙 30` 등)을 확인하고, 구역 위에 서서 코인을 투입해 **연사 석궁탑(1)**, **화염 대포탑(2)**, **빙결 수정탑(3)** 설치 및 최대 Lv.3 강화
- **총 3개 스테이지 순차 클리어**:
  1. **STAGE 1**: 초록 들판의 관문 (2 웨이브)
  2. **STAGE 2**: 옛 성벽의 굽잇길 (3 웨이브)
  3. **STAGE 3**: 왕국 본성 최후의 결전 (붉은 군단 대장 보스 포함 3 웨이브)
- **PC 16:9 가로형 반응형 화면**: 브라우저 창 크기가 달라져도 16:9 게임 뷰포트와 HUD/3D 건설 구역 배지가 정확히 맞춰지도록 구성

## 🚀 실행 방법

```bash
# 1. 의존성 설치 (최초 1회)
npm install

# 2. 개발 서버 실행 (브라우저에서 바로 플레이)
npm run dev

# 3. 프로덕션 빌드
npm run build
```

> `index.html`에 `importmap`이 설정되어 있어 `npx serve .` 또는 `python3 -m http.server 8080` 같은 정적 웹 서버로도 빌드 없이 즉시 실행할 수 있습니다.

## 🕹️ 조작 방법

| 조작 | 설명 |
| :--- | :--- |
| **마우스 이동** | 마우스 포인터가 가리키는 3D 지면 목표 지점을 향해 가속/감속하며 부드럽게 이동 |
| **적 접근** | 사거리 내 붉은 적 무리에게 자동으로 검을 휘둘러 범위 공격 |
| **마우스 좌클릭 / `Space`** | **황금 충격파 베기** 스킬 발동 (광역 피해 + 감속) |
| **건설 구역 위에 서기** | 보유 코인을 자동으로 투입해 선택된 방어탑 건설 및 강화 (최대 Lv.3) |
| **숫자키 `1` / `2` / `3`** | 건설할 방어탑 종류 선택 (`1`: 연사 석궁탑, `2`: 화염 대포탑, `3`: 빙결 수정탑) |
